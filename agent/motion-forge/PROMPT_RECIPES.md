# Starting briefs

Use these with the editor's **Copy prompt + current project** action, or attach the system prompt, scene reference and a valid example.

## CPU / memory / storage explanation

Create a 12-second technical motion graphic explaining a simplified CPU–RAM–storage data path. Use three grouped cards, Material `memory`, `storage` and `developer_board` icons, labelled bidirectional connections and moving particles. Clearly label the scene “simplified illustration”. Reveal nodes by 2 seconds, explain transfer directions next, then hold the complete diagram for 3 seconds. Use midnight blue, cyan and warm orange. Make all colours palette tokens. Return editable Motion Forge JSON.

## Brand image sequence

Use the existing logo asset ID in this project. Build an 8-second reveal with a dark radial background, a restrained scale-in logo, a two-line tagline and a final readable hold. Preserve the embedded asset marker exactly. Animate the panel, not a fake replacement of the logo. Include a transparent-background variant as a second scene.

## Evidence-led timeline

Using only the dated events supplied below, create a sequence of 10-second timeline scenes. Show no more than four events per scene. Give each event a year, concise label and source credit. Use provided article screenshot assets as evidence cards. Keep any unverified event out of the main timeline and flag it in the hand-off. Retain editable text and source metadata.

## Technical comparison

Build a 10-second animated bar chart from the values and units below. Do not change their meaning or normalize without saying so. Use a fixed, labelled scale and a visible source line. Animate bars from zero, introduce a counter only if it represents a supplied metric, and hold the final graph for 4 seconds. Use the paper palette for a bright documentary insert.

## Graphic from a reference

Use the reference for pacing, palette, spacing, camera-like 2D transforms and typography hierarchy. Describe the observable effects and build the parts this 2D renderer supports. Use original text and supplied assets. Identify any effects requiring 3D, compositing or an external editor. Return a valid editable project and a short list of those remaining production steps.
