# Starting briefs

Use these with the editor's **Smart director** (**✦ Build it for me** or **Copy smart prompt**), or attach the system prompt, scene reference and a valid example.

## One-line briefs (the director fills in the rest)

Each line alone builds a complete, illustrated multi-scene film. Add details only when you want to steer.

- `Launch video for our AI code review app in cyan and orange`
- `Recipe for fluffy pancakes: flour, eggs, milk, butter, maple syrup`
- `Quarterly results: revenue grew 42% to $3.5m, 1200 new customers, churn down to 2.1%`
- `Weekend in Kyoto, calm mood, 30 seconds`
- `Celebrate 10k followers with our community, warm`
- `How we keep your passwords safe with encryption, glass and liquid metal`
- `"Morning Flow" yoga routine for beginners: breathe, stretch, balance, rest`
- `Lesson explaining photosynthesis for students, light theme, 5 scenes`

Steering words: a quoted title, a length (`30 seconds`, `5 scenes`), colours, a mood (`light theme`, `warm`, `calm`, `neon`, `premium`), materials (`glass`, `liquid metal`, `water`, `gas`, `mirror`, `3D`, `no 3D`), a list after a colon, and real figures. Statistics appear only when you supply them.

## CPU / memory / storage explanation

Create a 12-second technical motion graphic explaining a simplified CPU–RAM–storage data path. Use three grouped cards, Material `memory`, `storage` and `developer_board` icons, labelled bidirectional connections and moving particles. Clearly label the scene “simplified illustration”. Reveal nodes by 2 seconds, explain transfer directions next, then hold the complete diagram for 3 seconds. Use midnight blue, cyan and warm orange. Make all colours palette tokens. Return editable Motion Forge JSON.

## Brand image sequence

Use the existing logo asset ID in this project. Build an 8-second reveal with a dark radial background, a restrained scale-in logo, a two-line tagline and a final readable hold. Preserve the embedded asset marker exactly. Animate the panel, not a fake replacement of the logo. Include a transparent-background variant as a second scene.

## Evidence-led timeline

Using only the dated events supplied below, create a sequence of 10-second timeline scenes. Show no more than four events per scene. Give each event a year, concise label and source credit. Use provided article screenshot assets as evidence cards. Keep any unverified event out of the main timeline and flag it in the hand-off. Retain editable text and source metadata.

## Technical comparison

Build a 10-second animated bar chart from the values and units below. Do not change their meaning or normalize without saying so. Use a fixed, labelled scale and a visible source line. Animate bars from zero, introduce a counter only if it represents a supplied metric, and hold the final graph for 4 seconds. Use the paper palette for a bright documentary insert.

## Graphic from a reference

Use the reference for pacing, palette, spacing, camera choreography and typography hierarchy. Describe observable effects and build supported SVG/WebGL components using original text and supplied assets. Identify effects that require fluid simulation, arbitrary mesh modeling, audio or an external editor. Return valid editable JSON and the remaining production steps.

## Glass product reveal

Build an 8-second technical product reveal using an original multi-part procedural model. Use a scene3d layer with glass, matte and liquidMetal parts, one planar mirror reflection, an establishing camera move and a stable final hold. Put readable SVG labels above the viewport. All tracks use scene-relative time. Show no unsupported logo or invented product specification. Deliver editable JSON and a deterministic MP4 command.

## Footage with animated overlays

Use the existing video asset ID, preserving its embedded-media marker. Place a video root layer behind a title, Lucide symbol and animated callout. Choose source trim and playback rate to match the supplied beat sheet; do not loop unless requested. Keep 5% safe margins and readable contrast. Do not promise source audio in export. Produce a complete JSON project and MP4/WebM export instructions.

## Material study

Create separate short shots comparing water ripples, animated liquid metal, translucent gas and glass refraction over other 3D objects. Use fixed seeds, simple geometry, controlled camera/light settings and explicit labels saying these are stylized procedural effects. Add a final shot demonstrating animated 2D shadow blur/offset. Validate and compare repeated timestamps before delivery.
